# Security

Report vulnerabilities privately. Do not open a public issue for an
unfixed secret, auth bypass, or injection.

- GitHub: use the repository's private vulnerability reporting, or email
  the maintainers listed on the GitHub org.
- Include the affected path, a minimal reproduction, and impact.
- We will acknowledge receipt and follow up with a fix or a reasoned
  decline.

Please do not attach production credentials, tenant data, or uploaded
media to a report.
